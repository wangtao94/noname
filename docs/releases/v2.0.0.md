# v2.0.0 · 服务端联机版

本 Fork 的第一个版本。在 [libnoname/noname](https://github.com/libnoname/noname) 的基础上，把联机改为**服务端权威**：对局在服务器上运行，浏览器只负责显示和操作。

## 亮点

- **房主掉线不影响对局**：房间和对局都在服务器上，房主只是持有管理权限的普通座位；大厅阶段房主离线 30 秒，房主身份自动移交。
- **断线自动续上**：网络波动时自动重连并补发错过的消息，60 秒内恢复对局无感知；超时由 AI 托管，回来后自动接管。浏览器崩溃或刷新后重新打开，也能回到原来的对局。
- **再来一局不刷新**：结算时后台预加载下一局，点击后约 1 秒切换，重新分配身份、重新洗牌，所有人留在房间里。
- **新的联机大厅**：房间号 + 邀请链接直接进房；房间设置按模式自动生成；空位开局时由 AI 补上。
- **内置插件「开局手牌 N 组选 1」**：每位玩家从 N 组起手牌中选一组；各身份组数可单独设置，默认自动计算。
- **扩展统一**：服务器管理员指定扩展，所有玩家加载同一份，避免各自扩展不同导致的异常。
- **一条命令部署**：单镜像、单端口，`docker compose up -d`；镜像支持 amd64 / arm64。
- **省流量**：图片和音频（约 1.2 GB）按内容缓存在浏览器里，二次访问几乎不耗流量，发新版只下载有变化的文件。

## 修复

- 联机房间缺少"出牌时限"默认值，导致玩家被立即判超时、踢出房间。
- 国战专属的九变篇牌包被混入身份局牌堆，使用时报错。

## 变更与兼容性

- 移除了上游的旧中继服务（`packages/server`）。旧版桌面和安卓客户端的"联机大厅"无法连接本服务器，请直接用浏览器访问。
- 本 Fork 不再发布桌面和安卓安装包；需要单机客户端请到上游获取。
- 服务器状态保存在内存中，重启服务会结束进行中的对局。

## 已知限制

- 联机协议会把手牌信息发送给所有客户端（继承自上游），改过的客户端可能看到他人手牌。
- 个别技能在联机时会在客户端报错，由出牌超时兜底，不影响对局继续（继承自上游）。
