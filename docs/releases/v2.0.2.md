# v2.0.2 · 满员开局修复与房间清理

## 修复

- **房间满员时无法正常开局**：人数坐满时，最后进入的玩家分不到座位，所有人停在"等待玩家"页面约 60 秒后才开局，且该玩家的座位被 AI 占用。现在人到齐后立即自动开局。
- 一局结束后若刷新了页面，房主在房间页看不到开局按钮。现在房间页显示"开始下一局"。

## 新增

- **解散房间**：房主可在房间页解散房间（对局进行中除外），点击后需再次确认；其他成员回到首页并收到提示。
- 房间列表不再显示所有成员都已离线的房间；最后一人离开时房间立即关闭。对局结束后关闭页面超过断线宽限期的成员会被移出房间，不再留下"幽灵"成员。

## 说明

联机对局的"等待玩家"页面只有"退出联机"和"分享房间"，没有开始按钮：所有人进入后由服务器自动开局；有人迟迟未进入时，最多等待 60 秒后开局，空位由 AI 补上。
