# v2.0.1 · 大厅易用性

在 v2.0.0 的基础上，重点改进联机大厅：新手不用研究设置，选好人数就能开局；熟手可以细调武将、卡牌和规则。

## 新增

- **新手推荐配置**：身份局新房间默认使用推荐配置（标准武将包、标准+军争牌堆，各身份候选武将 3 名），只需选择人数。改动其他设置后自动切换为"自定义"，可随时恢复推荐配置。
- **房间列表**：首页显示公开房间的模式、房主、人数和状态，一键加入。房间设置中可关闭"公开房间"。
- **武将包与卡牌包**：可选择本局使用的武将包和卡牌包，牌堆张数实时显示；可以查看每个包的内容（武将头像、势力、体力、技能说明；卡牌类型、张数、说明）。
- **禁用武将 / 禁用卡牌**：按名称搜索添加。
- **设置分组与说明**：房间设置分为基本、选将、规则、武将与卡牌、房间、插件六组，常用项直接显示，其余收在"更多设置"中；每个选项都有面向新手的说明（悬停或点"?"）。
- **开局手牌 N 组选 1**：选择"自动"时显示当前人数下各身份的实际组数。

## 改进

- 对局中打开房间面板后，可以通过"返回对局"按钮、Esc 或点击背景回到游戏；对局进行中设置只读。
- 镜像只构建 amd64，构建时间从约 15 分钟缩短到约 5 分钟。
- 服务端默认不再记录每个 HTTP 请求，日志更干净（`NONAME_LOG_LEVEL=debug` 时恢复）。

## 修复

- 同一浏览器在两个窗口打开同一局时互相顶掉、页面不停刷新。现在后打开的窗口接管对局，另一个窗口提示"本局已在另一个窗口打开"，可选择在此继续或返回房间。
- 对局页里个别技能的报错不再弹出阻塞对话框，改为大厅中的非阻塞提示。

## 兼容性

- 不支持 ARM（arm64）机器。
- 服务器状态仍保存在内存中，重启服务会结束进行中的对局。
